### `ticket-writer`

Sabe aquele clássico *"preciso de um botão azul pra ontem, acho que é rápido"*? 

A skill **`ticket-writer`** é o exorcista oficial de tickets vagos:
- 🎯 **Foco no valor real**: questiona o impacto de negócio antes de qualquer linha ser escrita.
- 🏷️ **Classificação esperta**: infere se é Tarefa, Bug, User Story, Spike ou Sub-task.
- 🛡️ **Blindagem de código**: nomes de arquivos, funções e variáveis são mantidos exatamente como você definiu.
- 🚫 **Zero LaTeX fantasma**: formatação em Markdown puro e limpo, sem quebrar o editor do Jira.
- ✅ **Critérios de Aceite à prova de dúvidas**: testáveis e diretos ao ponto.

## 🚀 Como Usar

Você pode instalar diretamente no seu projeto via CLI de skills:

```bash
# Adiciona a skill ao seu repositório/workspace
npx skills add olavocneto/skills --skill ticket-writer
```
